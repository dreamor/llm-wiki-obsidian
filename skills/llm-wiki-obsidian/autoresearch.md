# AutoResearch — 自主研究技能

> 本文档是 [SKILL.md](SKILL.md) 的子技能，定义自主研究循环的完整流程。

## 何时使用

- 用户要求"研究 X"、"深入了解 X"
- 用户要求 `/autoresearch [主题]`
- 知识库中存在明显的知识缺口需要填补

---

## 研究流程

3 轮迭代循环：搜索 → 抓取 → 综合 → 摄入

### Round 1: 广泛搜索

```
1. 使用 web search 搜索主题关键词
2. 收集 5-10 个高质量来源（优先：官方文档、学术论文、权威博客）
3. 评估来源可信度（见 program.md 配置）
4. 记录来源列表
```

### Round 2: 深度抓取

```
1. 逐个抓取 Round 1 收集的来源
2. 提取关键信息、实体、概念
3. 识别与已有 Wiki 的关联和矛盾
4. 标记需要进一步研究的子主题
```

### Round 3: 综合摄入

```
1. 将所有来源摄入 Wiki（按 wiki-ingest.md 流程）
2. 创建 Synthesis 页面综合分析
3. 更新 index.md
4. 记录日志
5. 识别剩余知识缺口（可选继续研究）
```

---

## 置信度评分

每个来源和主张的置信度：

| 等级 | 标准 | 示例 |
|------|------|------|
| **高** | 官方文档、同行评审论文、权威作者 | PyTorch 官方文档、arXiv 论文 |
| **中** | 知名博客、技术报告、行业分析 | Hugging Face Blog、OpenAI 技术报告 |
| **低** | 论坛帖子、个人博客、未经验证的信息 | Reddit 讨论、个人技术博客 |

在 Wiki 页面中标注置信度：
```markdown
> [!info] 置信度：高
> 来源：[[PyTorch 官方文档]]
```

---

## 配置

编辑 `references/program.md` 自定义研究行为：

- **来源偏好**：优先学术、官方文档、还是新闻
- **置信度阈值**：低于此阈值的来源不摄入
- **最大轮次**：默认 3 轮
- **每轮最大页面**：默认 10
- **领域约束**：如"优先 PubMed"或"聚焦市场数据"

---

## 命令

```
/autoresearch [主题]        # 启动 3 轮研究
/autoresearch [主题] --deep # 5 轮深度研究
/autoresearch [主题] --quick # 1 轮快速研究
```

---

## 完成标准

- [ ] 至少 3 个高质量来源已摄入
- [ ] 所有新页面已创建并交叉引用
- [ ] index.md 已更新
- [ ] 日志已记录
- [ ] 剩余知识缺口已标注（如有）
